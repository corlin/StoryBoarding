## 💎 革命性核心能力清单

### 1. 📖 长篇小说 / 剧本一键成剧 (Multi-Episode Series Compiler)
- **万字长篇无痛导入**：支持直接粘贴 **500 ~ 20,000 字** 的小说高潮章节、网络文学或连续剧本企划；
- **Stage 1 交互式透视抽屉 (Series Blueprint Drawer)**：
  - AI 在 2~3 秒内秒级提取**全局角色卡（主角/反派/配角）**及人物性格动机；
  - 自动为每位角色生成纯英文**视觉基因锚点 (Visual DNA Anchor)**，彻底终结跨集角色“换脸”难题；
  - 智能切分 **3~5 集短剧（每集 60~90s）**，算法强制将每集末尾截断在扣人心弦的**生死悬念或惊天反转 (Cliffhanger Hook)**；
- **Stage 2 微观并发逐集拆拍**：
  - 创作者确认大纲后，系统并发调用好莱坞拆镜引擎，极速为每集拆出 8~12 个镜头并自动注入角色视觉 DNA。

---

### 2. 🚀 单场灵感一键升维扩写 (Scene-to-Series Expansion Engine)
- **从灵感火花到商业全集**：创作者在工作台打磨出 30 秒惊艳的单场戏后，无需推倒重来；
- 点击 **【🚀 扩写为连载短剧】**，已有 12 镜自动固化为 **「EP 1 · 首播集」**，AI 编剧自动基于集尾生死卡点推演后续 2~4 集全新大纲与分镜，旧工程平滑升维为多集短剧！

---

### 3. 🎭 全剧视听基因中枢 (Unified Visual Bible)
- **单一真实数据源 (Single Source of Truth)**：彻底消除“角色库”与“设定集”两套割裂系统的冗余；
- **双 Tab 统一中枢**：
  - **🎭 全剧角色定妆谱**：集中管理全剧所有角色的定妆人设、性格标签与纯英文 Visual DNA 提示词基准；
  - **🏛️ 核心场景空间锁**：固化全剧关键地理空间的建筑材质、光影氛围与环境反射隐喻（Environment Anchors）；
  - **🎨 导演画风基准**：好莱坞经典石墨素描、电影明暗大反差、局部荧光点缀等风格预设。

---

### 4. ⚡ 戏剧节拍状态树与双视界情绪时间轴 (Dual-Scale Emotional Voltage Timeline)
- **商用成瘾性节拍体系**：

## 🚀 快速开始 (本地开发)

本项目彻底废除了笨重迟钝的 Docker 依赖，直接通过 Node.js 与 `wrangler` 极速轻量驱动。

### 1. 安装依赖

```bash
# 安装后端 Workers 依赖
cd backend && npm install

# 安装前端依赖
cd ../frontend && npm install
```

### 2. 启动本地开发服务

```bash
# 终端 1：启动后端 Cloudflare Worker (端口 http://localhost:8787)
cd backend && npm run dev

# 终端 2：启动前端 Next.js (端口 http://localhost:3000)
cd frontend && npm run dev
```

### 3. 一键部署到 Cloudflare

#### 部署后端 Workers:
```bash
cd backend
npx wrangler d1 create storyboard_db
npx wrangler r2 bucket create storyboard-assets
npm run deploy
```

#### 部署前端 Pages:
```bash
cd frontend
npm run build
npx wrangler pages deploy .next
```
